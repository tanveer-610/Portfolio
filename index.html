    01 — Selected work

    Now TechnoNext Software Ltd.

    PayNext: payment gateway

    A payment service orchestrator that lets merchants accept cards, mobile wallets and net banking through one integration. It covers hosted and embedded checkout, a card-data vault, merchant and admin portals, settlement batches and signed webhooks.

    What I work on

    • Card-data security. Each checkout session gets its own ECDH key, and card secrets are encrypted in the browser with AES-GCM via HKDF before they leave the page.
    • Payment channels. Visa, Mastercard and AMEX through acquirer banks, bKash wallets, and City Touch net banking, all routed through one processor and integration layer.
    • Merchant webhooks (IPN). One final, signed notification per order. Payloads are signed with rotating merchant credentials, and retries are safe.
    • Notification platform. Email, SMS, push (FCM) and webhooks, with per-category provider chains and ordered failover.
    • Rates and reconciliation. Versioned TDR/MDR rates with effective windows, BIN ranges, refunds, and batch settlement files.
    • Embedded SDK. A checkout iframe merchants can drop into their own pages, with origin allow-lists and Playwright end-to-end tests.

    Architecture

    Checkout app Checkout API Processor Integration Bank / MFS

    Plus card-data, fraud, notification, link-payment, report, batch, merchant and admin services. They talk over tiered REST (public, portal and inter-service) and Kafka.

    Previously TechnoNext Software Ltd.

    OTA: multi-tenant travel platform

    An online travel agency platform for hotels, tours and visas. It was built tenant-first, so the same deployment serves several travel brands, each with its own branding, invoices and configuration.

    FirstTrip Triplover TakeOff Travels

    What I built

    • Tenant-aware backends. Hotel, Tour and Visa services resolve the tenant on every request, and invoices, refund documents, colours, watermarks and paid seals all follow the brand.
    • Reporting. Branded invoices, refund invoices and reports generated with JasperReports, rendered per tenant.
    • Search. Fast, typo-tolerant search with Meilisearch.
    • Schema migrations. Database changes versioned and rolled out with Liquibase.
    • Supplier integration. Live hotel search, pricing and booking through the TBO supplier API, mapped into the platform's own model.
    • Admin back-office. Separate admin services for inventory, bookings, refunds and reporting per product line.
    • B2C frontend. A Next.js and TypeScript storefront styled with Tailwind.
    • Test automation. API test suites in Playwright for Java with TestNG, covering the B2B booking flows.

    Shipped for

    FirstTrip, plus a separate deployment for the client Triplover, both on the same codebase.
